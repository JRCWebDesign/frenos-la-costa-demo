# Frenos La Costa

Demo estática de diseño para un taller de frenos en Ciudad de la Costa.

Abrir `index.html` o servir la carpeta con `python -m http.server 8080`.
GitHub Pages sirve la raíz de la rama `main`.

## Contenido

Servicios, teléfono y dirección transcritos de las capturas de Instagram aportadas para la demo. La opinión de Ángel Correa es un extracto, con omisión indicada, de una reseña compartida por el taller. No se afirma una puntuación global ni un total de opiniones.

La portada del auto es una ilustración generada. El logo está recortado del perfil de Instagram aportado. La hora de cierre y el pin exacto quedan pendientes de confirmar. El botón de presupuesto abre una llamada telefónica. El enlace del mapa hace una búsqueda por nombre y dirección.

Fuente del negocio: https://www.instagram.com/frenos_la_costa/

Tipografía Barlow, distribuida bajo SIL Open Font License. Licencia y créditos en `assets/OFL.txt`.

Reseñas adicionales transcritas del perfil de Google enlazado por el usuario. Se muestran extractos breves con autor y enlace al perfil. Íconos SVG propios en amarillo para Instagram, WhatsApp, Google y Facebook. El ícono de Facebook abre el diálogo para compartir la demo. El enlace del perfil del taller queda pendiente de aportar.
